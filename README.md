# CodeAlpha Hangman Game

A simple **Hangman Game** built using Python as part of the CodeAlpha Python Programming Internship.

## About the Project

This is a beginner-friendly word guessing game. The player tries to guess the secret word by entering one letter at a time.

The player has a limited number of incorrect guesses. The game continues until the player either guesses the word correctly or reaches the maximum number of incorrect guesses.

## Features

* Randomly selects a word from a predefined list
* Allows the player to guess letters
* Keeps track of guessed letters
* Detects repeated guesses
* Counts incorrect guesses
* Provides a maximum of 6 incorrect guesses
* Displays the game result

## Technologies Used

* Python
* `random` module

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project in Python/pycharm.
4. Run the Hangman Python file.
5. Enter one letter at a time to guess the secret word.
