# CodeAlpha_Hangman_Game
Hangman Game

A simple text-based Hangman Game developed in Python as part of my CodeAlpha Python Programming Internship.

Features
Randomly selects a word from a predefined list
Player guesses one letter at a time
Shows the guessed letters in the word
Allows a maximum of 6 incorrect guesses
Checks duplicate guesses
Shows a win or game-over message
Technologies Used
Python
Random module
While loop
If-else statements
Lists
Strings
How to Run

Run the Hangman_Game.py file in Python and follow the instructions shown in the console.
